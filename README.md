# Theatre MVP - Информационная система театра

## Описание проекта
Веб-приложение для управления театральными билетами и заявками. Проект разработан в рамках производственной практики по модулю ПМ.05 «Проектирование и разработка информационных систем».

## Функционал
- **Для зрителей:**
  - Регистрация и авторизация (с валидацией и AJAX-проверкой уникальности логина).
  - Просмотр адаптивной афиши с фильтрацией по жанрам.
  - Создание заявок на покупку билетов.
  - Имитация платежного шлюза (оплата заявки).
  - Личный кабинет с историей покупок и визуальным прогресс-баром статусов.
  - Чат с поддержкой в реальном времени.
  - Смена пароля через модальное окно.

- **Для администратора:**
  - Дашборд со статистикой (пользователи, заявки, выручка).
  - Управление всеми заявками (фильтры, пагинация, смена статуса через AJAX).
  - Управление афишей (добавление и удаление спектаклей).
  - Чат поддержки (возможность писать пользователям первым).

## Стек технологий
- **Backend:** PHP 8.x (PDO)
- **Database:** MySQL (15+ таблиц, связи, внешние ключи)
- **Frontend:** HTML5, CSS3 (Flexbox, Grid, адаптив 390x844), JavaScript (Fetch API, DOM)
- **СУБД:** Open Server Panel / phpMyAdmin

## Установка и запуск
1. Клонируйте репозиторий.
2. Разместите файлы в папке `domains` вашего веб-сервера (например, Open Server).
3. Импортируйте SQL-скрипт из папки `db/schema.sql` в вашу базу данных MySQL.
4. Настройте подключение в файле `db.php` (хост, имя БД, пользователь, пароль).
5. Откройте проект в браузере.
