# Theatre MVP - Информационная система театра

## Описание предметной области
Веб-приложение для театра. Позволяет пользователям просматривать спектакли, создавать заявки на покупку билетов, а администраторам — управлять этими заявками и менять их статусы.

## Основные сущности базы данных
- **users** — пользователи системы (логин, ФИО, телефон, email, пароль).
- **roles** — роли (администратор, пользователь).
- **performance** — спектакли (название, длительность, жанр, базовая цена).
- **hall / seat** — залы и места.
- **orders** — заявки пользователей (к какому спектаклю, количество билетов, статус).
- **payments** — информация об оплате.

## Реализованные сценарии (Модуль 1)
1. **Регистрация:** валидация полей, проверка уникальности логина, запись в БД.
2. **Авторизация:** вход по логину и паролю, разграничение прав (пользователь/админ).
3. **Личный кабинет:** просмотр своих заявок, форма создания новой заявки.
4. **Админ-панель:** просмотр всех заявок, изменение статуса (new → paid → cancelled).

## Стек технологий
- **Backend:** PHP
- **Database:** MySQL (phpMyAdmin)
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript
